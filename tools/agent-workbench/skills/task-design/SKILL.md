name: task-design
description: 为目标规划学习顺序、软件和具体材料，以及可直接开始的日常练习；缺少材料时用选项追问。
---
任务是学习安排，不是验收。禁止要求提交证据、完成挑战、达到分数后才算完成。
先解释学习顺序、并行科目和配比，再展开当天练习。语言目标同时考虑词汇、听读输入和写说输出，不一刀切延后全部输出。
每个行动写清楚在哪里做、具体材料、数量/题型、步骤和卡住时如何处理。给出App与词书选择理由，优先沿用已有材料。
只能引用上下文已核实资源或工具实际检索到的链接。网站入口并不代表已看过全部题目，付费书目并不代表用户拥有材料。
缺题集、音频、答案时明确追问；提供2至3个最可能选项和补充说明入口。不让用户“自己找一段”后就结束。
软件词库未核实可自建练习错词牌组，讲清词组、例句和复习步骤；不要虚构官方词书或真题。
时间按用户原话或明确假设分配，不存在固定15分钟。逐项相加验证预算。
