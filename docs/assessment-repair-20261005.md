- 统一配置生成策略：`DSH_REASONING_EFFORT=high`、`DSH_MAX_TOKENS=16384` 为默认值，同一配置同时传给 provider 与 SDK 会话。上限可设 1024–32768，整体超时仍默认 120 秒；实际成本取决于用量，无自动重复调用。
- 所有任务共用完成检查：额度耗尽、错误、中断、拦截及未知/缺失结束事件均拒绝。正常结束但无结果、JSON 语法错误、字段校验错误分别分类。没有自动修补 JSON、放宽输出 schema 或跳过领域约束。
- 安全诊断只记录白名单结束原因、字符数、输出 token 数、配置额度/推理强度、固定语法类别与数字位置；不保存失败正文、推理内容或供应商异常消息。
- 评估上下文从本次提交投影，保留完整成果、用途、帮助声明和不可变标准快照。历史反馈、重试前的评价、XP、其他阶段和可变路线不作为本次证据。`criterion/challenge` 定义通过要求，`exercise/steps` 是练习建议。
- 个人标准为 null 仍能判断文字达标，但不产生公共认证；有帮助的挑战和空泛自述仍不通过。原文引用、帮助标记、路线版本、阶段归属和目标状态的领域检查全部保留。
