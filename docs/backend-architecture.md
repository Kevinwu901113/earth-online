# 后端架构

## 运行边界

浏览器 → 同源 Fastify API → PostgreSQL。独立 worker 从 PostgreSQL 领取任务，启动官方 DSH SDK 子进程；Redis 保存 30 分钟的短期上下文缓存。DSH 使用 `@deepseek-ai/dsh-sdk-client@0.2.0-rc.2`，配置 `sdk-minimal` 并移除其中默认带有的终端和子进程工具。

模型仅可调用 earth_context、earth_standards、earth_search。没有数据库凭据、写库工具、用户会话、父进程环境或 shell 工具。每个任务有独立 DSH home，最多 8 个 agent 请求、8 次工具调用、单次输出 6000 tokens，整体超时默认 120 秒。SDK/供应商内部网络重试不等同于新 agent 请求；整体超时是最终预算边界。执行结束删除临时上下文与运行日志，worker 异常退出遗留目录按运行手册清理。

模型输出经过结构校验、来源凭据核对、目标版本校验、标准版本校验、原文引用校验，再在事务中落库。DSH 返回的建议永远不直接执行。搜索使用固定 Exa 端点，不让模型控制服务器任意请求 URL。检索内容是不可信材料。用户确认建议后仍走与表单相同的业务命令。

`schemas.js` 的 `outputSchemas` 是路线、评估、对话和复盘的唯一输出契约。`agent-output.js` 从相同 Zod schema 生成模型收到的 JSON Schema，并在模型返回及事务结算入口校验。字段类型不匹配时拒绝结果，不做数组转字符串、放宽校验或自动补造内容。字段级诊断仅保留契约版本、字段路径、问题代码、预期/实际类型、长度和上下限，最多20项；不保存失败回复原文、任意对象键或供应商错误正文。

## 持久状态

| 表 | 职责 |
| --- | --- |
| users / sessions | scrypt 密码摘要、随机会话的 SHA-256 摘要、到期时间 |
| players | 每用户 JSONB 聚合状态与乐观版本，行锁串行化该用户的变更 |
| command_receipts | 用户 + 请求键唯一；网络重试回放相同响应，键复用不同命令拒绝 |
| growth_ledger | 来源 + 类型唯一的不可重复记账记录；只由业务规则计算 |
| domain_events | 操作审计，不保存完整敏感输入 |
| agent_jobs | 持久队列、租约、终态、错误与结果；与触发命令同一事务 |
| public_standards | 标准 ID + 版本唯一；已发布版本不更新 |

选择 JSONB 用户聚合是为了当前业务的一致性和可迭代性。大用户历史、跨用户报表及高并发场景应把记录分表/分页；当前不宣称已做规模压测。Redis 不承担队列、成长账本或历史记录，缓存丢失从 PostgreSQL 重建。缓存键含用户和状态版本，避免串号和读取旧画像。

## 业务约束

- 主线创建后仅为 draft；路线必须由用户确认才 active。每次确认增加 revision，保留完成阶段和旧路线。最终阶段标准总是包含最初确认的目标完成条件。
- 路线后台结果绑定最新请求 ID、revision 和 stage；过时结果不提交。同一目标已有 queued/running 规划时拒绝重复调整，取消后可重新规划。多个 worker 的领取事务短暂串行，每个用户最多一个 running 任务，跨用户可以并行。
- 目标的 planning 是读取时从 agent_jobs 派生的状态，不在 players 中复制维护。目标卡片和详情直接显示排队、生成、失败和取消；后台任务最近50条的显示上限不影响目标状态。重试清除旧草案但保留已确认路线；旧目标可通过已有任务关联读取失败状态。
- 命令的 expectedVersion 防止覆盖其他标签页/后台任务的更新。冲突后刷新，不静默重放不同意图。
- 投入 XP 为 growth-v1：每 5 分钟 1 XP、单次最多 12、每日最多 40、每 100 XP 升一级；属性只是投入分类。休息 0 XP，不扣分。服务端保管规则版本。
- 练习不推进阶段。挑战必须独立、文字可评估、有原文证据且符合固定标准。自述、链接、音视频或使用帮助只能保留为证据不足；没有公共标准就不颁发公共成就。
- 模型评分不是权威能力认证，原文引用校验只能防止虚构引用，不能证明模型判断正确。真实质量验收及公共认证还需要运营抽查。
- 最终需要现实结果的目标停在 awaiting_external；用户提交外部证据后由运营核实，不能自行点击完成。
- 手动生活事件使用 externalId 去重。事件本身不发 XP，避免同一次活动再记一次成长。机会超过领取或执行期限即失效；过期不扣分。
- 记忆修改保留上一版及修正时间，不篡改提交成果和账本。删记忆只删摘要；账号全量删除由运营入口处理。
- 任务失败、超时或租约过期都不会自动重试模型，以免重复计费/重复生成。原始提交保留，用户可主动重试；取消后晚到结果不得落库。
